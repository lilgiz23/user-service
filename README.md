# user-service

Моё домашнее задание по Hibernate. Консольная программа: можно добавлять, смотреть, менять и удалять пользователей. Данные хранятся в PostgreSQL.

Автор: Гаймалетдинов Ильгиз

## Как запустить
1. Поставить PostgreSQL и создать базу `userservice`
2. В файле `src/main/resources/hibernate.cfg.xml` поменять логин на свой
3. Запустить `Main`

Таблицу программа создаёт сама.
